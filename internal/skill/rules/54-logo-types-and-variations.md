# Rule: Logo Types and Variations

**Domain:** branding · **ID:** `54-logo-types-and-variations`

## Purpose
Picks the right mark type for a name and a category, then builds the lockup ladder that keeps it legible from a 16 px favicon to a shopfront. It prevents the common failure of one masterpiece shrunk into mush.

## Definition
Five canonical types: wordmark (name set as type), lettermark (initials), pictorial (a recognizable object), abstract (a non-object form), emblem (type enclosed in a badge), plus the combination lockup of mark and wordmark. Variations are the delivery set: horizontal, stacked, icon plus wordmark, icon only, mono, reversed — each with its own minimum size.

## Core Principles
- Wordmark when the name is short (roughly 12 characters or fewer) and distinctive; it names and identifies in one read, which no other type does.
- Lettermark when the name is long (three words or more) and the initials are already known. Introduced cold, initials hide the name you paid to build.
- Pictorial when one concrete object sits at the core of the offer. Abstract when the idea is broader than any object, and accept that it needs repetition before it means anything.
- Emblem when the mark must read as badge or seal (breweries, universities, sports clubs). The trade is small-size legibility: below 32 px an emblem becomes a smudge.
- The combination lockup is the safest default: the mark works before the name is known, the name works while the mark is not.
- Every type needs four or five variations with assigned minimum sizes. A single-size logo is one that will be stretched by someone in a hurry.

## Techniques
1. **Pick by test, not taste** — set the name at 24 px cap height. If it is unreadable, the wordmark fails. If the initials mean nothing to a stranger, the lettermark fails.
2. **Responsive ladder** — five steps: full lockup ≥200 px, stacked 120–200 px, icon plus wordmark 48–120 px, icon only below 48 px, and a simplified 16 px favicon.
3. **Hold the mark ratio constant** — mark height fixed while wordmark size changes; drifting proportions read as two brands.
4. **Alignment per type** — center-stack emblems, left-align combination lockups, and keep the gap between mark and wordmark equal to the clear-space unit.
5. **Design in one color first** — if the mark fails in black, no second color rescues it. Add color only after the one-color version is approved.

## When to Use
- A new identity, before the first application is built.
- Auditing an existing logo whose small-size version is a scaled-down copy of the large one.
- When a brand expands into formats it was not designed for: app icon, embroidery, favicon, signage.

## When to Avoid
- Forcing five variations onto a brand with two touchpoints — build the formats that exist.
- Inventing a pictorial mark where no distinctive object exists; you will land on a lightbulb, a leaf, or a swoosh.

## Common Mistakes
| Mistake | Why it fails | Fix |
|---|---|---|
| Wordmark that blurs at 24 px | Hairline strokes and tight spacing close up | Wider tracking, sturdier cut, or a lettermark below 48 px |
| Icon-only on first contact | Reader cannot connect mark to name | Combination lockup until the mark is known |
| Five variants, five proportions | Reads as several brands | Fixed mark height and gap across the set |
| Emblem scaled to 16 px | Detail collapses into noise | Simplified badge or icon-only variant |

## Practical Examples
"Rill Coffee" — five files: wordmark 190×44 with 24 px cap height and +3% tracking; stacked lockup 160×120; combination 260×48 with a 40 px tall three-arc mark; icon-only 40×40 with a 24 px minimum; favicon 16 px using two arcs and no wordmark. The mark's 40 px height is identical in the combination and stacked versions, so the set reads as one logo in five lengths.
