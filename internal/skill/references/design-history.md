# Design history — reference

Use when a brief asks for a historical style, or when you need to know *why* a convention exists.
Rules: [`100-design-movements`](../rules/100-design-movements.md) and the movement rules
[`101-bauhaus`](../rules/101-bauhaus.md) through [`110-retro-and-vintage-design`](../rules/110-retro-and-vintage-design.md).

## Timeline that matters for design decisions

| Period | Movement | Core idea | Visual shorthand |
|---|---|---|---|
| 1910s–20s | Constructivism | Art as agitation and construction | Diagonals, red/black, photomontage, condensed type |
| 1917–31 | De Stijl | Universal order through reduction | Primary colors, black orthogonals, asymmetric balance |
| 1919–33 | Bauhaus | Form follows function; craft + industry | Geometric primitives, sans type, functional objects |
| 1920s–30s | Art Deco | Modernity as luxury and speed | Symmetry, stepped forms, metallic, geometric ornament |
| 1950s–60s | Swiss / International | Objective communication through systems | Grid, Helvetica/Univers, asymmetry, flush-left type |
| 1960s–70s | Psychedelia / counterculture | Experience over clarity | Warped type, saturated color, dense ornament |
| 1970s–80s | Postmodernism | Irony, quotation, pluralism | Layered type, pastiche, broken grids |
| 1981–87 | Memphis | Playful commercial rebellion | Clashing color, squiggles, patterns, asymmetry |
| 1990s–2000s | Grunge / deconstructivism | Digital texture and disorder | Distressed type, layered grunge, illegibility |
| 2010s– | Flat → Neobrutalism | Honesty of material, then aggressive candor | Flat color → thick borders, hard shadows, raw type |

## How to use a movement without pastiche

1. **Take the constraint, not the costume.** Swiss style is not "Helvetica and red". It is
   alignment to a grid, asymmetric balance, and one type family doing hierarchy through scale.
2. **Reproduce the logic.** Ask what problem the movement solved, then apply the same solution
   to the current problem. Bauhaus solved "how does craft meet mass production"; that question
   still exists.
3. **Limit the borrow.** One movement per piece. Mixing Bauhaus geometry with Deco luxury and
   Swiss grids produces genre confusion.
4. **Respect era-accurate details** if the goal is authenticity: paper stock, print artifacts
   (misregistration, ink spread), typefaces actually available at the time, halftone screens.
5. **Modernize the production, not the look.** Clean vectors, correct color management, and
   restrained effects. A 1960s poster recreated with drop shadows is neither.

## Pitfalls

| Pitfall | Why it fails | Better |
|---|---|---|
| Style as decoration | The reference does not serve the message | Pick the movement that solves the current problem |
| One-typeface "Swiss" | Swiss style is a system, not a font | Build the grid, then choose the type |
| Retro filters on modern layouts | Two eras in one artifact | Commit to era-accurate production details |
| Quoting without attribution | Looks like taste, reads as theft | Name the reference to the client |
| Over-ornamenting minimalism | Contradicts the premise | Remove until it breaks, then add one thing back |
