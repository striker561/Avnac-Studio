# Creating a Design From a Brief

## Applies when
There is a request, a deliverable and no existing artifact. This is the general entry skill; if
the deliverable is clearly a poster, logo, UI screen, package or print job, use that skill
instead and keep this one for the first hour of work.

## Workflow
1. **Extract the brief into five lines.** Audience, message, deliverable, constraints (brand,
   size, language), deadline. If two of the five are missing and the design cannot proceed
   without them, ask at most three questions and stop. Otherwise state assumptions explicitly —
   an explicit wrong assumption is cheap to fix; a silent one is not.
2. **Choose the format before the layout.** Match the format to where it will be seen, not to
   what is easy: feed post 1080×1350 px, story 1080×1920 px, interview banner 1920×1080 px,
   A4/A3 print at 300 PPI, favicon 32×32 px. Format decides hierarchy, not the reverse.
3. **Write the words first.** Headline, subhead, one line of body if needed, call to action or
   details. Designing around placeholder text produces placeholder hierarchy.
4. **Pick one visual strategy.** Type-led, image-led, illustration-led, or geometric/graphic.
   Choose the one that carries the message with the least explanation. Two strategies at once
   produces a composition with two voices.
5. **Set the grid.** Margins 5–8% of the short edge for screen, 1/9–1/12 for print. Two or three
   columns. Place the primary element on a column edge or a third line — not floating in the
   middle by feel.
6. **Establish hierarchy with three sizes.** Body, secondary, primary, then derive the rest from
   one ratio (1.25–1.5 step). Write the actual values down before placing text.
7. **Draft fast and ugly on purpose.** Get all elements on the canvas at roughly correct size
   and position, in flat values, before any styling. Decisions made on a complete, rough
   composition are better than decisions made on one polished corner.
8. **Do one refinement pass against the checks below**, then stop. Further passes without new
   information dig the same hole.

## Decision points
- **Center or asymmetric?** Centered for ceremony, single message, luxury, symmetry-as-meaning.
  Asymmetric for energy, editorial, modern, and when the content has unequal parts.
- **One color or many?** If the brand has no palette, start monochrome plus one accent. Adding
  color later is easy; removing it after it has become structural is not.
- **Photo or no photo?** Use imagery when the message is a scene, a person, or a place. Skip it
  when the message is a claim or a number — stock imagery weakens claims.
- **Print or screen final?** It changes color space, resolution, bleed and type sizes. Decide
  before drafting twice.

## Production checks
- Canvas size is final and matches the stated use.
- All text is real text, not lorem ipsum.
- One element is clearly first; squint at 25% zoom to confirm.
- Text sits 4–6% inside the edges; nothing important within 3 mm of trim on print work.
- Colors have roles: background, primary, accent, text. No orphan colors.

## Output format
Deliver: the artifact, a one-line message statement, the hierarchy table (level, size, weight,
color), the palette with roles, and the assumptions you made. If the user gave a brand, note
which brand assets you used or approximated.
