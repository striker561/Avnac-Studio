# Branding — reference

Use when the work is identity rather than a single artifact. Rules:
[`50-brand-strategy`](../rules/50-brand-strategy.md) through
[`58-rebranding-and-evolution`](../rules/58-rebranding-and-evolution.md).

## The chain (each link constrains the next)

```
audience → positioning → personality → identity system → applications → guidelines
```

If a visual decision cannot be traced back up this chain, it is decoration.

## Strategy inputs to collect

| Input | Question | Output |
|---|---|---|
| Audience | Who must choose this, and against what alternatives? | One primary segment, one sentence |
| Category | What is this *a kind of*? | Category convention to follow or break |
| Differentiator | What is true and ownable? | One claim, provable |
| Personality | If the brand were a person, how would it speak? | 3–5 adjectives with opposites |
| Proof | Why believe it? | Products, data, heritage, people |
| Constraints | Legal, cultural, competitive, budget | Non-negotiables |

## Positioning statement template

> For **[audience]** who **[need/occasion]**, **[brand]** is the **[category]** that
> **[differentiator]**, because **[proof]**.

One sentence. If it needs two, the strategy is not decided yet.

## Identity system layers

| Layer | Elements | Failure mode |
|---|---|---|
| Core mark | Logo, lockups | Too detailed to survive small sizes |
| Color | Primary, secondary, functional | Too many colors → no recognition |
| Type | Display + text + fallback | Font not licensed for the needed media |
| Imagery | Photography, illustration, icon style | Style mix reads as several brands |
| Layout | Grid, templates, spacing rules | No templates → every asset looks new |
| Motion / sound | Easing, timing, audio | Ignored in print-only systems (fine) |
| Voice | Vocabulary, tone, examples | Visual and verbal personalities disagree |

A system is working when a new asset can be made by someone who has never met the designer and
still looks native.

## Recognition economics

- Recognition comes from **repetition of few elements**, not from variety of expression.
- Rule of thumb: a brand needs 5–8 consistent exposures before it is recognized; every
  inconsistent asset spends one.
- Distinctiveness beats likeability in testing: a liked-but-generic identity loses to a
  distinctive one over time.
- Own a color or a shape others do not use. Being "clean and modern" is not ownable.

## Guidelines that get used

Include, in this order:
1. One-page summary (the "if you read nothing else" page).
2. Logo: files, clear space, minimum size, misuse examples.
3. Color: values in HEX/RGB/CMYK/Pantone, ratios, accessibility pairs.
4. Type: families, licences, scale, fallbacks, do/don't specimens.
5. Layout: grid, margins, templates (real, editable files).
6. Imagery: style, subject rules, treatment, sourcing.
7. Voice: tone, vocabulary, example sentences.
8. Applications: 6–10 real examples, not mockups of fantasy products.

## Consistency audit

| Check | Method | Pass |
|---|---|---|
| Logo usage | Collect the last 20 assets | Same lockup logic, clear space respected |
| Color | Sample the assets | Within the defined palette and ratios |
| Type | Inspect 10 assets | Only licensed families, correct scale |
| Layout | Compare 10 assets | Grid and margins recognizably the same |
| Voice | Read 5 pieces | Same person speaking |
| Accessibility | Check 5 pairs | Meets contrast minimums |

## Rebrand decision matrix

| Situation | Usually right | Usually wrong |
|---|---|---|
| Audience changed | Reposition + refresh | Full rebuild without strategy |
| Category changed | New identity | Keep the old mark "for equity" |
| Mark fails at small sizes / digital | Redraw + variants | Keep and add complexity |
| Equity is strong, execution dated | Evolution | Radical change for novelty |
| Leadership wants "modern" with no reason | Do nothing yet | Rebrand as a personality project |
