# Rule: Character and Object Design

**Domain:** illustration · **ID:** `65-character-and-object-design`

## Purpose
Design characters and objects that are identifiable from shape alone, expressive with minimal features, and
consistent across a series made by different hands over months.

## Definition
Character design assigns a silhouette, a proportion system, a face grammar, a pose vocabulary, and a prop set, so
that the character is recognizable at 24 px and reproducible by someone else.

## Core Principles
- Silhouette first. Fill the character black and view at 10%: if you cannot name it, it is not designed. Everything
  else is detail on a shape that must already work.
- Proportion sets the read. Head-to-body 1:2 reads iconic or toy, 1:3–1:4 reads friendly and is safest for
  explainer work, 1:6–1:8 reads realistic. Use one ratio for the whole cast.
- One identifying shape per character: a hat, a hair mass, a bag, or a tool. Two characters sharing three
  attributes will be confused at small sizes.
- Expression is placement, not detail: two dots and a mouth line carry six emotions, and moving the mouth 10% of
  head width changes the read more than eyelashes do.
- Pose needs a line of action. A straight vertical spine reads stiff; a curve from head through hip to the
  supporting foot reads alive. Weight the pose onto one foot.
- Props follow logic: correct scale to the hand, graspable, and consistent across the series. A prop that changes
  shape breaks the cast faster than a color drift.

## Techniques
1. **Silhouette sheet** — five poses in solid black at 400 px tall on one canvas. Delete any pose you cannot
   identify in black.
2. **Proportion sheet** — divide the character's height into head units and mark the eye, shoulder, hip, and hand
   lines as y coordinates, so every later drawing can be checked against numbers.
3. **Expression sheet** — six faces at 96 px from one head base: neutral, happy, concerned, surprised, focused,
   tired. Keep the eyes fixed and change only brow and mouth.
4. **Small-size reduction** — redraw at 24 px with no outline and three shapes. If the character survives, the icon
   version is done.
5. **Object triple** — front, side, and top views at the same scale, so the object stays buildable when it
   reappears at another angle.

## When to Use
- A recurring mascot, a guide character in onboarding, or a cast that must appear across a campaign.
- Object illustration inside a system — packaging, devices, tools — where the same item reappears at three sizes.
- Any series where a different illustrator will draw the character later.

## When to Avoid
- A single one-off image with no series: a silhouette sheet is overhead you will not recoup.
- Icons at 16–24 px. A character reduced to a glyph loses the identifying shape; use a symbol instead and let the
  character live at larger sizes.

## Common Mistakes
| Mistake | Why it fails | Fix |
|---|---|---|
| Detail added before silhouette | The character is only readable in close-up | Design black at 10% first |
| Each pose drawn from scratch | Proportions drift between images | Work from one proportion sheet |
| Expressions drawn as new faces | The cast stops looking like one person | Fix the eyes, vary brow and mouth |
| Props scaled by eye | The object looks unholdable | Scale the prop to the drawn hand |

## Practical Examples
A guide character on 1080×1080: 3.5 head units tall, silhouette built from a `path` hood that breaks the head
outline, so it reads at 24 px. Six expressions on one 96 px base, eyes fixed as `#12100E` circles of r=4. The prop
— a clipboard — is 1.4× the hand width and sits at the same angle in all four spots.
